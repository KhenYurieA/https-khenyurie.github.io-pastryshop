# Sweet Cravings Bakeshop Portfolio

## 🍩 Overview
Sweet Cravings Bakeshop is a sample portfolio project showcasing a bakery website.  
It includes product listings, order forms, store hours, and contact information.

## ✨ Features
- Responsive design with HTML & CSS
- Product cards with images and descriptions
- "Add to Cart" functionality (JavaScript)
- Franchise and Learn More sections with clickable buttons
- Contact details and store schedule
